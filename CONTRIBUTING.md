# Contributing

Use the [bug report or feature request form](https://github.com/Dry-Candy6689/Illucet/issues/new/choose) to open an issue. A blank issue is also available. For bugs, include the app/iOS versions, steps to reproduce and a redacted error message. Keep account details, cookies, signed media URLs and device identifiers out of reports.

Use [Development](docs/Development.md) to build and test. Keep changes focused, add a regression case for behavior changes, and describe the relevant checks in your pull request. Offline fixtures and simulator results do not establish live-service or physical-device behavior.

Contributions to Illucet's original code are provided under GPL-3.0, matching the project license. Preserve third-party notices.
