# Security

Report vulnerabilities using GitHub's private vulnerability reporting for this repository. Avoid posting credentials, cookies, signed media URLs or private media in public issues.

Include the affected version, a minimal reproduction and the expected security boundary. Only test content and accounts you are authorized to access.

Illucet's boundaries include exact media selection, file containment, private account storage, bounded parsing and verified extractor updates. See [Architecture](docs/Architecture.md) and [extractor update security](docs/UpdaterSecurity.md).
